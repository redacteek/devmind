📌 Purpose

anthropic-sdk-python is the official Python client library for the Anthropic API. It provides a clean, type-safe interface to interact with Claude models, handling authentication, request construction, streaming, and error management out of the box.

⚙ Tech Stack

Built entirely in Python 3.8+, the SDK uses httpx for async/sync HTTP, pydantic for model validation, and anyio for async primitives. Type hints are enforced throughout via mypy.

🏗 Architecture

The project follows a clean resource-based architecture:

  • Anthropic / AsyncAnthropic — root client classes
  • resources/messages.py — Messages API endpoint implementation
  • types/ — auto-generated Pydantic response models
  • _base_client.py — shared HTTP logic, retry, auth
  • lib/streaming.py — SSE stream helpers

🚀 Entry Points

Users instantiate anthropic.Anthropic() which reads ANTHROPIC_API_KEY from the environment. The client.messages.create() method is the primary entrypoint for all LLM calls.
